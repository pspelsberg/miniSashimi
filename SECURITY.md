# Security Policy & Coordinated Vulnerability Disclosure (CVD)

This project (miniSashimi) is designed with modern security, privacy, and compliance principles in mind. In accordance with the **EU Cyber Resilience Act (CRA)**, we maintain active security patch support and provide clear channels for reporting security issues.

## Supported Versions

We support security updates for the following versions:

| Version | Supported | Support Until |
| ------- | --------- | ------------- |
| 1.0.x   | Yes       | Dec 31, 2030  |
| < 1.0.0 | No        | Unsupported   |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** open a public issue. Instead, report it privately to our security team.

Please send your report to: **security-disclosure@minisashimi.local**

Your report should include:
- A detailed description of the vulnerability.
- Steps to reproduce or a Proof of Concept (PoC).
- Potential impact and mitigation ideas.

We will acknowledge receipt of your report within **24 hours** (in compliance with CRA early warning requirements), provide a status update within **72 hours**, and work towards releasing a fix or advisory within **14 days**.

## Security Audits & SBOM

We maintain an up-to-date Software Bill of Materials (SBOM) in SPDX/CycloneDX format. You can generate the current SBOM by running the development dependency scanners or referencing the release artifacts.
